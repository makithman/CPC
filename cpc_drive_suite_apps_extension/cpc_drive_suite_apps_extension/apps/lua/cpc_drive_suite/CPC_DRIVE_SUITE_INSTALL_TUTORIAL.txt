CPC DRIVE SUITE - INSTALLATION TUTORIAL
========================================

This package contains two parts:

1. The CPC Drive Suite shelf app
2. The matching CSP NeckFX cockpit backend

The ZIP preserves the folders needed for Assetto Corsa. Extract it into the
Assetto Corsa installation folder, not into the Windows Roaming folder.

FOLDER LAYOUT
-------------
After extraction, the files must be here:

  apps/lua/cpc_drive_suite/
    cpc_drive_suite.lua
    cpc_drive_suite_core.lua
    cpc_drive_suite_settings.lua
    cpc_drive_suite_settings_file.lua
    CPC_DRIVE_SUITE_SETTINGS.JSON
    CPC_DRIVE_SUITE_DEFAULTS.JSON
    ...other CPC app files...

  extension/lua/cockpit-camera/default/
    cockpit.lua
    manifest.ini
    settings.ini

INSTALLATION
------------
1. Close Assetto Corsa and Content Manager.
2. Open the Assetto Corsa installation folder.
3. Extract the ZIP contents into that folder.
4. Allow Windows to merge the apps and extension folders.
5. Start Content Manager and Assetto Corsa.
6. Open CSP NeckFX / scripted cockpit camera settings.
7. Select the CPC Drive Suite NeckFX backend from the cockpit-camera scripts.
8. Reload the session.
9. Open the CPC Drive Suite app from the Assetto Corsa app menu.
10. Open the NeckFX page and confirm that the backend says BACKEND ONLINE.

SETTINGS FILES
--------------
CPC_DRIVE_SUITE_DEFAULTS.JSON is the shipped default profile. It is not changed
when the user saves settings.

CPC_DRIVE_SUITE_SETTINGS.JSON is the user save-state profile. It contains the
current user tuning and is saved automatically when the app closes. It can also
be saved manually from the Home page with SAVE JSON.

To restore the shipped profile, use LOAD DEFAULTS FROM JSON. This applies the
values from CPC_DRIVE_SUITE_DEFAULTS.JSON and makes them the active reset values.

To restore the user profile manually, use LOAD JSON. The JSON files are plain
text and can be edited with a text editor, but keep valid JSON syntax and keep
setting values as numbers, booleans, or strings of the same type.

HOME PAGE JSON TOOLS
--------------------
SAVE JSON              Save the current user settings.
LOAD JSON              Load the user save-state settings.
LOAD DEFAULTS FROM JSON
                       Restore CPC_DRIVE_SUITE_DEFAULTS.JSON.
OPEN JSON FOLDER       Open the project folder containing both JSON files.
VIEW JSON              Display the user JSON inside the app.

RESET BEHAVIOR
--------------
Right-clicking a slider restores its current default.
System reset buttons restore their system defaults.
Full reset restores all values from the shipped default profile.

TROUBLESHOOTING
---------------
BACKEND OFFLINE:
- Confirm the backend files are in extension/lua/cockpit-camera/default/.
- Select the CPC Drive Suite cockpit backend in CSP NeckFX.
- Reload the session.

EXPORT FAILED:
- Confirm the app is installed in the Assetto Corsa apps/lua folder.
- Confirm CPC_DRIVE_SUITE_SETTINGS.JSON is writable.
- Do not place the project only in the Windows Roaming folder.

INVALID JSON:
- Ensure the file begins with { and ends with }.
- Use double quotes around setting names.
- Use true/false for boolean values.
- Remove trailing commas.

DISPATCHING THE PROJECT
-----------------------
The project contains no user-specific drive, Steam library, or account paths.
The app resolves its folders from the Assetto Corsa root supplied by CSP.
The backend and shelf app must keep their relative folder locations.
